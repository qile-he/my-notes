>C语言的函数调用，在机器层面是怎么实现的

## 三个基本机制
### Passing Control：控制流传递
`jmp`只会跳转，不会记录从哪里跳过来

`call`会自动保存跳转地址
注意：返回的是下一条机器指令的地址，而不是call的地址

### Passing Data：数据传递
|参数|寄存器|
|---|---|
|第 1 个|`%rdi`|
|第 2 个|`%rsi`|
|第 3 个|`%rdx`|
|第 4 个|`%rcx`|
|第 5 个|`%r8`|
|第 6 个|`%r9`|
第7个之后的参数通常通过栈传递

### Memory Management：内存管理

---
## x86-64的stack
1. 后进先出（LIFO, Last In, First Out）
2. 在x86-64中，栈往**低地址方向增长**

- Stack Bottom：相对较高的地址。
- Stack Top：相对较低的地址。
- `%rsp`：Stack Pointer，指向当前栈顶。

### `pushq`和`popq`
```asm
pushq %rax
```
等价于：
```asm
subq $8, %rsp
movq %rax, (%rsp)
```


```asm
popq %rbx
```
等价于：
```asm
movq (%rsp), %rbx
addq $8, %rsp
```
The memory doesn't change, only the value of `%rsp`.
也就是说，原来的内存数据没有被清除，只是位置不属于当前的栈空间

## 函数调用与参数传递

`call` 执行两件事：
1. 将返回地址（Return Address）压入栈中。
2. 将控制流跳转到目标函数。

`%rip`保存当前执行位置的指令指针

|指令|栈操作|控制流变化|
|---|---|---|
|`call`|压入返回地址，`%rsp -= 8`|跳到目标函数|
|`ret`|弹出返回地址，`%rsp += 8`|跳回返回地址|

最重要的结论：`ret` 不需要知道调用者是谁。它只需要取出当前栈顶保存的返回地址。

被调用函数必须保证 `%rbx` 在返回时保持原值

## 栈帧 Stack Frame
```
高地址
┌─────────────────────────┐
│ Caller 的栈帧            │
│                         │
├─────────────────────────┤
│ 传入的第 7 个及以后参数    │
├─────────────────────────┤
│ Return Address          │  ← call 压入
├─────────────────────────┤
│ Old %rbp （可选）        │
├─────────────────────────┤
│ Saved Registers         │
├─────────────────────────┤
│ Local Variables         │
├─────────────────────────┤
│ 为下一次调用准备的空间     │
└─────────────────────────┘  ← %rsp
低地址
```
第一，栈帧大小不固定。
不同函数需要的栈空间不同。有的函数只需要保存一个寄存器，有的函数需要保存很多局部变量。

第二，`%rbp` 并不一定存在于函数的栈帧管理中。
传统上，`%rbp` 可以作为 Frame Pointer（帧指针），方便访问栈帧中的数据。
但现代编译器经常省略帧指针，直接通过 `%rsp` 访问。

第三，并非所有函数都需要分配栈空间。

| 指令                   | `%rdi` 得到什么     |
| -------------------- | --------------- |
| `leaq 8(%rsp), %rdi` | `v1` 的地址        |
| `movq 8(%rsp), %rdi` | `v1` 的值，即 15213 |

注意：call 调用时会压入一个8字节的返回地址

## 寄存器保存约定
>Register Saving Conventions

### Caller-safed：调用者负责保存
### Callee-saved：被调用者负责保存

| 寄存器                                          | 类型           | 用途           |
| -------------------------------------------- | ------------ | ------------ |
| `%rax`                                       | Caller-saved | 返回值          |
| `%rdi`, `%rsi`, `%rdx`, `%rcx`, `%r8`, `%r9` | Caller-saved | 参数传递         |
| `%r10`, `%r11`                               | Caller-saved | 临时变量         |
| `%rbx`, `%r12`, `%r13`, `%r14`               | Callee-saved | 临时变量         |
| `%rbp`                                       | Callee-saved | 可用作帧指针       |
| `%rsp`                                       | 特殊           | 函数返回前需要恢复栈指针 |
