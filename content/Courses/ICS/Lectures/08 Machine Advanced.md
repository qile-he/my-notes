## Unions
- `struct`：每个成员拥有独立的存储空间。
- `union`：所有成员共享同一块存储空间，起始地址相同。

联合体的大小不仅取决于最大成员，还要满足对齐要求

联合体最重要的用途：重新解释位模式

x86-64 使用小端序（Little Endian），低有效字节放在低地址

- ASLR：地址空间布局随机化
- NX：不可执行栈
- Stack Canary：栈保护值
Canary 是编译器在栈中设置的一段特殊值。
它通常位于局部缓冲区与保存的返回地址之间。
其基本思路是：
> 如果缓冲区越界写入，一直覆盖到返回地址，那么中间的 Canary 很可能也会被覆盖。函数返回之前检查 Canary，就能发现异常。

| 防御方式         | 主要作用           |
| ------------ | -------------- |
| ASLR         | 让攻击者难以预测地址     |
| NX           | 阻止执行注入到栈中的机器指令 |
| Stack Canary | 检测某些栈缓冲区越界写入   |

Return-Oriented Programming（ROP，面向返回的编程）
ROP 不尝试向栈中注入新的机器指令，而是利用程序中原本存在、具有执行权限的代码片段。
这些片段被称为 Gadget。
