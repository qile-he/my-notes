## 2.89

### 答：
| 选项  | 是否总为 1 | 核心原因                               |
| --- | ------ | ---------------------------------- |
| A   | 是      | `int → double` 精确，两边转 float 的舍入一致  |
| B   | 否      | `x-y` 可能发生整数溢出                     |
| C   | 是      | 三个 32 位整数的和在 double 中始终可以精确表示      |
| D   | 否      | 乘积可能超过 double 的 53 位有效精度，结合顺序影响舍入  |
| E   |  否     | `0/0 = NaN`，且 `NaN == anything` 为假 |
