注意运用  $2^m*n == n<<m$

`1<<31 != 0x80000000`因为类型不同

二分法（1、2、4、8、16）

`x>>31`可以作为判断正负数的mask

`!!x`可以用来把非零值规范成1

分别mask，最终用`|`合并，起到选择的作用

| 常量           | 典型 32-bit C 类型 |
| ------------ | -------------- |
| `0x7fffffff` | `int`          |
| `0x80000000` | `unsigned int` |
| `0xffffffff` | `unsigned int` |
