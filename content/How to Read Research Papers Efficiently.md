## Compile lists of papers

## Take multiple passes through the paper

1. Read the title/abstract/figures
2. Read the intro + conclusions + figures and Skim the rest (Skim related work section)
3. Read but skim/skip math
4. Read the whole thing but skip parts that don't make sense

## Questions that I should ask myself after reading

- What did the authors try to accomplish?
- What were the key elements of the approach?
- What can you use yourself?
- What other reference do you want to follow?

## Math

- Read through it
- Take detailed notes
- See if you can rederive it from scratch

## Code

- Download and run the open source code
- Reimplement it from scratch
